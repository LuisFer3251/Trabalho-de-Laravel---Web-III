# Laravel Web III Project

Projeto acadêmico e de estudo desenvolvido com Laravel, com foco em desenvolvimento web full stack, arquitetura MVC, integração com banco de dados e organização de aplicação.

## Objetivo

Aplicar conceitos de desenvolvimento web com PHP e Laravel, incluindo rotas, controllers, views, migrations e lógica de negócio em uma aplicação organizada e funcional.

## Stack

- PHP
- Laravel
- MVC
- MySQL
- HTML
- CSS

## Funcionalidades

- Estrutura MVC
- Rotas e controllers
- Views com Blade
- Banco de dados com migrations
- Organização de aplicação web
- Desenvolvimento de lógica e regras de negócio

## Status

Projeto acadêmico concluído e mantido como material de estudo e demonstração de conhecimento em desenvolvimento web.

## Tecnologias Principais

- PHP
- Laravel
- Composer
- MySQL
- Git / GitHub
